# picoCTF

Writeups for picoCTF and picoGym challenges. / picoCTF ve picoGym challenge writeup'ları.

**Naming / Adlandırma:** `YYYY-MM-DD-room-name/README.md`, screenshots in `img/`.
Example / Örnek: `2026-05-17-challenge-name/README.md`

Create one with / Şu komutla oluştur:

```bash
python tools/new_writeup.py --platform picoctf --name "Challenge Name"
```

**Check before publishing / Yayınlamadan önce kontrol et:** picoCTF's current rules on sharing
solutions (especially during a running competition), and never publish flags. /
picoCTF'in çözüm paylaşma kuralları (özellikle devam eden yarışma sırasında); flag'leri asla yayınlama.
