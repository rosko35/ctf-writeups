# TryHackMe

Writeups for TryHackMe rooms. / TryHackMe odalarının writeup'ları.

**Naming / Adlandırma:** `YYYY-MM-DD-room-name/README.md`, screenshots in `img/`.
Example / Örnek: `2026-05-17-room-name/README.md`

Create one with / Şu komutla oluştur:

```bash
python tools/new_writeup.py --platform tryhackme --name "Room Name"
```

**Check before publishing / Yayınlamadan önce kontrol et:** TryHackMe's current rules on
publishing writeups, and never publish flags. / TryHackMe'un writeup yayınlama kuralları; flag'leri asla yayınlama.
