# HackTheBox

Writeups for HackTheBox machines and challenges. / HackTheBox makine ve challenge writeup'ları.

**Naming / Adlandırma:** `YYYY-MM-DD-room-name/README.md`, screenshots in `img/`.
Example / Örnek: `2026-05-17-machine-name/README.md`

Create one with / Şu komutla oluştur:

```bash
python tools/new_writeup.py --platform hackthebox --name "Machine Name"
```

**Rule / Kural:** HackTheBox forbids publishing writeups for active machines and challenges.
Only publish retired content, and never publish flags.
HackTheBox aktif makine ve challenge'lar için writeup yayınlamayı yasaklar. Yalnızca emekli
(retired) içerik yayınla ve flag'leri asla yayınlama.
