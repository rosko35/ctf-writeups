# Other

Writeups from other platforms or from my own lab. / Diğer platformlardan veya kendi laboratuvarımdan writeup'lar.

**Naming / Adlandırma:** `YYYY-MM-DD-room-name/README.md`, screenshots in `img/`.
Example / Örnek: `2026-05-17-challenge-name/README.md`

Create one with / Şu komutla oluştur:

```bash
python tools/new_writeup.py --platform other --name "Challenge Name"
```

**Rule / Kural:** Only legal, intentionally vulnerable targets; check the platform's rules; never
publish flags. / Yalnızca yasal, kasıtlı zafiyetli hedefler; platform kurallarını kontrol et; flag'leri asla yayınlama.
